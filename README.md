# Angular Getting Started

Starter Angular moderno con Angular 21, componenti standalone, PrimeNG e Tailwind CSS.

## Avvia il progetto

```bash
npm install
npm start
```

Apri `http://localhost:4200/`.

## Comandi

- `npm start` — server di sviluppo
- `npm run build` — build di produzione
- `npm test` — test con Vitest

## Stack

- Angular 21 + segnali
- PrimeNG con tema Aura
- Tailwind CSS 4
- TypeScript in modalità strict

Modifica `src/app/app.html` e `src/app/app.ts` per iniziare.
